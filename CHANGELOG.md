# Changelog

All notable changes to the Zap VS Code extension are documented here.

## [1.0.0] - 2026-08-21

### Stable release

- Stabilized native Zap LSP integration over stdio JSON-RPC.
- Added completion, hover, definition, signature help, workspace symbols, formatting, diagnostics, and language-server restart support.
- Added canonical Zap `say` syntax highlighting and removed non-canonical `print` output suggestions.
- Added built-in snippets for functions, async functions, control flow, modules, classes, collections, JSON, filesystem, environment variables, HTTP, Result/Option workflows, and async tasks.
- Added project custom snippet examples through `examples/zap-custom.code-snippets`.
- Added format-on-save, lint, build, test, and recovery commands.
- Added Zap logo and `.zp` file icon theme.
- Updated English and Burmese documentation.

## [0.8.0]

- Expanded the built-in Zap snippet catalog.

## [0.7.0]

- Added built-in and project custom snippet templates.

## [0.6.0]

- Aligned output syntax and quick fixes with the canonical Zap `say` syntax.

## [0.5.1]

- Synchronized async task tooling with the native Zap runtime.
